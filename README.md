# WoW AddOns (`_forever_`)

我的 World of Warcraft 插件集合备份，路径对应 `Interface/AddOns`。

| 插件 | 说明 |
| --- | --- |
| `AutoAutoLoot` | 自动拾取 |
| `BigFootSync` | 大脚数据同步 |
| `DanielAddon` | 自用背包整理插件（材料优先入材料包、按分类分袋、袋内独立排序） |
| `EasyAuction` | 拍卖行辅助 |
| `Questie` | 任务助手 |
| `QuestieDB` | Questie 数据库 |
| `QuestieTrace` | 任务追踪调试工具 |

## 说明

- `QuestieDB/QuestieDB_*.toc` 是由 `lua generate.lua Forever` 生成的数据库文件，文件头标注「do not commit」；本仓库为完整备份仍予以保留。
- `DanielAddon` 原为一个独立 git 仓库，其历史已备份至同级目录 `../DanielAddon-git-backup-20261114`（不在本仓库内），本仓库中作为普通文件跟踪。
